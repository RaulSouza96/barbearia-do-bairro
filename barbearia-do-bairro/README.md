# Barbearia do Bairro

Landing page de um comércio fictício para praticar HTML e CSS. Usa a estrutura da missão de imobiliária, com cinco seções centralizadas e cores de fundo alternadas. Não usa JavaScript nem frameworks.

## Abrir

Abra o arquivo index.html no navegador. Mantenha as pastas css e img junto dele. O mapa depende de conexão com a internet.

## Entender o código

- A tag meta charset="UTF-8" permite exibir acentos.
- A meta viewport adapta a área de visualização à tela do dispositivo.
- A tag link conecta o HTML ao arquivo css/estilo.css.
- Cada div com classe secao agrupa uma parte da página.
- Os links href="#servicos", por exemplo, levam ao elemento com id="servicos".
- A classe secao aplica espaçamento e alinhamento a todas as seções.
- As classes topo, servicos e contato mudam a cor de fundo.
- A lista ul reúne os serviços sem numeração.
- O iframe exibe um mapa do Google Maps.
- width define uma largura; max-width: 100% evita que imagens ultrapassem o espaço disponível em telas pequenas.
- Os arquivos SVG são ilustrações locais, exibidas com img, sem depender de um banco de fotos.

## Personalizar antes de entregar

Leia o HTML e o CSS. Troque os textos, as cores ou o nome por escolhas suas e confira o resultado. Saiba explicar por que o menu funciona e onde ficam os estilos de cada seção. Este projeto foi preparado com auxílio de IA; siga as regras do curso sobre esse uso e descreva sua participação com precisão.

A barbearia é fictícia. O mapa mostra a cidade de Antônio Carlos/SC e não um endereço comercial. O e-mail usa o domínio reservado .example e não recebe mensagens. Em um projeto real, substitua-o por um contato válido.

## Publicar

1. Crie um repositório público no GitHub.
2. Envie index.html, README.md e as pastas css e img diretamente para a raiz do repositório.
3. Na Vercel, importe o repositório e selecione o preset Other. Não é necessário comando de build.
4. Se os arquivos estiverem dentro de uma pasta, configure Root Directory para essa pasta.
5. Publique e teste o menu, as imagens e o mapa.
6. Envie ao curso os links do repositório e do site publicado.
